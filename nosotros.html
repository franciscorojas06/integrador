Sobre MOKA ZONE

¿Qué es MOKA ZONE?

MOKA ZONE es un sitio web educativo dedicado a los videojuegos. Su objetivo es reunir información básica, imágenes y formas de contacto en un solo lugar.

Objetivos del proyecto

  • Presentar un catálogo sencillo de videojuegos.
  • Organizar el contenido mediante distintas páginas.
  • Facilitar la navegación desde computadoras y celulares.
  • Ofrecer un formulario de contacto de ejemplo.
Historia del proyecto

El sitio fue pensado como una práctica de desarrollo web utilizando HTML para la estructura, CSS para el diseño y JavaScript para algunas interacciones.
